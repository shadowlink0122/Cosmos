# Cosmo Linux ABI拡張 (v0.2.0)

## 概要

Cosmo Linux v0.2.0ではLinux x86_64 syscall ABIを大幅に拡張し、
musl-libc静的リンクバイナリの実行をサポートする基盤を構築した。

## 実装構造

```
sys/
├── syscall_table.cm    # syscall番号定義 (50+種)
├── syscall.cm          # メインディスパッチャ + 基本syscall
├── syscall_fs.cm       # FS系: stat/lseek/openat/getdents64等
├── syscall_proc.cm     # プロセス系: clock_gettime/getrandom等
└── syscall_net.cm      # ネットワーク系: socket/connect等

exec/
├── elf.cm              # ELF64パーサ (ET_EXEC + ET_DYN/PIE)
└── loader.cm           # ELFローダー (auxv/argc/argv構築)
```
