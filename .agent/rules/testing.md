# テスト規約

## テスト手法

### QEMUによる統合テスト
```bash
make run    # QEMUでOSを起動（OVMF自動取得）
```

### シリアル出力テスト
- QEMUの `-serial mon:stdio` でシリアル出力をキャプチャ
- 期待出力との比較で自動テスト化可能

### テストファイル配置
```
tests/
├── boot/       - ブートテスト
├── mm/         - メモリ管理テスト
├── drivers/    - ドライバテスト
└── scripts/    - テストスクリプト
```

## テスト作成ガイドライン
1. **最小限のテスト** - 1テスト1機能
2. **シリアル出力で結果報告** - UART経由で PASS/FAIL を出力
3. **境界値テスト** - メモリ境界、ポインタ操作のエッジケース
4. **QEMU再現性** - テストは常にQEMU上で再現可能であること

## 新機能追加時
1. docs/os_design.md で設計を確認
2. 実装を行う
3. QEMUで動作確認
4. 必要に応じてテストスクリプト作成
