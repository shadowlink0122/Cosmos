# バグ修正ワークフロー

## 1. 問題の特定
1. バグの再現手順を確認
2. QEMUで再現確認
// turbo
3. シリアル出力・フレームバッファ出力でデバッグ情報確認

## 2. 原因調査
1. アセンブリコードの確認（UEFIオフセット等）
2. メモリマップの確認（GDB接続 or シリアル出力）
3. 関連コードの確認

## 3. 修正実装
1. 修正コード作成
2. 最小再現コードで動作確認
// turbo
3. QEMUで動作確認: `make run`

## 4. 回帰テスト
// turbo
1. QEMUで全機能テスト
2. 回帰がないことを確認

## 5. コミット
1. 修正内容をコミット
2. 関連Issueがあればリンク
