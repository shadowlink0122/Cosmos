# カーネル機能実装ワークフロー

## 0. 事前確認
- `docs/os_design.md` との整合性確認
- 実装フェーズ（Phase 1-4）のどこに該当するか確認
- Cmの`no_std`環境で実現可能か確認

## 1. 設計フェーズ
// turbo
1. `docs/` に設計ドキュメント作成
   - ファイル名に`00N_`プレフィックスを付ける
2. 既存カーネルコードへの影響分析
3. 必要なASM操作の洗い出し

## 2. 実装フェーズ
1. 最小限の実装から開始
2. 段階的に機能追加
3. 各段階でQEMU動作確認
4. シリアルコンソールでデバッグ出力

## 3. 検証フェーズ
// turbo
1. QEMUでビルド＆起動: `make clean && make && make run`
2. シリアル出力で期待動作を確認
3. メモリリーク等の問題がないか確認

## 4. ドキュメント更新
1. `docs/os_design.md` の該当フェーズを更新
2. `README.md` を更新（実装状況）
3. 設計ドキュメントを`docs/archive/`に移動（実装完了時）

## 5. コミット
// turbo
1. 変更をコミット
2. 一貫性チェック：
   - [ ] カーネル実装 ✓
   - [ ] QEMUテスト ✓
   - [ ] docs更新 ✓
   - [ ] README更新 ✓
