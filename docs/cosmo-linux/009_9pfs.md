# Cosmo Linux — 9pファイルシステム (virtio-9p VFS統合)

## 概要

QEMUのvirtfsを通じてホストディレクトリをゲストにマウントする機能。
`/mnt/host` パスでホストの `rootfs/` ディレクトリにアクセス可能。

## アーキテクチャ

```
シェルコマンド (ls /mnt/host, cat /mnt/host/xxx)
        │
        ▼
    cmd.cm (パス判定 → NinePfs APIに委譲)
        │
        ▼
    ninepfs.cm (VFSブリッジ: walk→lopen→read→clunk)
        │
        ▼
    virtio_9p.cm (9P2000.Lプロトコル実装)
        │
        ▼
    QEMU virtfs (ホストディレクトリ共有)
```

## 使い方

### QEMU起動
```bash
make run
# Makefile内で -virtfs local,path=./rootfs,mount_tag=host,security_model=none を指定
```

### シェルコマンド
```
cosmo:/$ ls /mnt/host       # ホストディレクトリの一覧
cosmo:/$ cat /mnt/host/hello.txt  # ホストファイルの内容表示
cosmo:/$ hostls              # ルートの一覧 (直接)
cosmo:/$ hostcat hello.txt   # ファイルの内容 (直接)
```

## ファイル構成

| ファイル | 内容 |
|---------|------|
| `drivers/virtio_9p.cm` | virtio-9pドライバ (PCI, virtqueue, 9P2000.Lプロトコル) |
| `fs/ninepfs.cm` | VFS統合ブリッジ (NinePfs struct) |
| `include/vfs.cm` | FS_9PFS定数 |
| `fs/vfs.cm` | 9pfsパス判定追加 |

## 9P2000.L プロトコル操作

| 操作 | 用途 |
|------|------|
| Tversion/Rversion | バージョンネゴシエーション |
| Tattach/Rattach | ルートFIDにアタッチ |
| Twalk/Rwalk | パスをウォーク |
| Tlopen/Rlopen | FIDをオープン |
| Tread/Rread | ファイル読み取り |
| Treaddir/Rreaddir | ディレクトリ一覧 |
| Tgetattr/Rgetattr | ファイル属性取得 |
| Tclunk/Rclunk | FID解放 |
