## v0.1.0 — Foundation (現在のブランチ)

カーネルの基盤を確立し、対話的なシェル環境を提供する。

### 実装済み

- [x] UEFIブートローダ（ExitBootServices + BootInfo引き渡し）
- [x] GDT/TSS設定（Long Mode フラットセグメント）
- [x] IDT/ISR（例外ハンドラ0-31、リカバリ機構）
- [x] PIC初期化 + 割り込み制御
- [x] 物理メモリマネージャ（ビットマップ方式）
- [x] 仮想メモリ管理（UEFI CR3継承）
- [x] カーネルヒープアロケータ（256KB）
- [x] PIT タイマー（100Hz）
- [x] スケジューラ（ラウンドロビン）
- [x] PS/2キーボードドライバ（IRQ1、スキャンコード→ASCII変換）
- [x] フレームバッファコンソール（8x16フォント、カラー出力）
- [x] シリアルコンソール（COM1 115200 8N1）
- [x] CosmFS（インメモリファイルシステム、ディレクトリ階層）
- [x] initramfs（起動時ファイル展開）
- [x] 対話的シェル（19コマンド、コマンド履歴、カーソル編集）
- [x] CosmEXEローダ（PE→VA配置フラットバイナリの動的実行）
- [x] Syscallインタフェース（int 0x80、SYS_WRITE/READ/EXIT）
- [x] 環境変数システム
- [x] パス解析（絶対/相対パス対応）
- [x] Ariaテキストエディタ（インカーネル）

### 残作業

- [ ] Cmインタプリタ（`cm <file>`コマンド）
- [ ] テストカバレッジ拡充

## v0.2.0 — Isolation

ユーザモードの導入とプロセス分離により、安全なマルチタスク環境を実現する。

### 計画

- Ring 3 への遷移（`sysret`/`iretq`によるユーザ↔カーネル切り替え）
- `syscall`/`sysret` 命令ベースの高速システムコール
- ユーザ空間ページテーブル分離（プロセスごとのCR3）
- ELF/CosmEXEローダ（ユーザ空間へのバイナリロード）
- プロセス管理（fork的なタスク生成、wait、exit）
- IPCメカニズム（メッセージパッシング）
- シグナル機構

## 設計原則（全バージョン共通）

### 1. Cm First
全てのコードはCm言語で記述する。インラインアセンブリ（`__asm__`）はハードウェア操作の最小限に留める。

### 2. 軽量さの維持
カーネルのメモリフットプリントを最小化する。不要な抽象化層を避け、直接的な実装を優先する。

### 3. 段階的なカーネル進化
```
v0.1.0  モノリシック（全サービスがカーネル空間）
  ↓
v0.2.0  モジュラーモノリシック（サービス分離の準備）
  ↓
v0.3.0+ ハイブリッド（FSサーバ等をユーザ空間に移行）
  ↓
v1.0.0  マイクロカーネル志向（最小カーネル + ユーザ空間サービス）
```

### 4. テスト駆動
各カーネルコンポーネントにユニットテストと統合テストを作成し、QEMUヘッドレスモードで自動検証する。
