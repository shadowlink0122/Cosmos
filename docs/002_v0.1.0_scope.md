# v0.1.0 スコープ定義

> Cosmos OS の最初のリリース。UEFIブートからカーネル初期化までを実装する。

## ゴール

**UEFI環境上で動作するメニュー式カーネルシェル**

既存のCm UEFIサンプルをベースに、以下を実現する：

1. UEFIブートローダとして起動し、カーネルバナーを表示
2. メモリマップの取得・表示
3. キーボード入力の処理
4. GOPフレームバッファによるグラフィクス描画
5. シリアルコンソール（UART）デバッグ出力の追加

## v0.1.0 に含める機能

### 必須（Must）

| 機能 | 状態 | 説明 |
|------|------|------|
| UEFIブート | ✅ ベース完成 | `efi_main` エントリポイント |
| テキスト出力 | ✅ ベース完成 | UEFI ConOut経由のテキスト表示 |
| キーボード入力 | ✅ ベース完成 | ブロッキング/非ブロッキング入力 |
| メモリマップ表示 | ✅ ベース完成 | GetMemoryMapによるメモリ情報表示 |
| GOP初期化 | ✅ ベース完成 | フレームバッファアドレス取得 |
| 描画プリミティブ | ✅ ベース完成 | ピクセル、線、矩形描画 |
| シリアルコンソール | ❌ 未実装 | UART 0x3F8 へのデバッグ出力 |
| ルートMakefile | ✅ 完成 | `make` / `make run` でビルド＆QEMU起動 |
| CI/CDパイプライン | ✅ 完成 | サブモジュールビルド＋ブートテスト |

### 任意（Nice to have）

|------|------|
