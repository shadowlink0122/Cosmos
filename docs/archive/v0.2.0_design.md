# v0.2.0 設計書: ユーザー空間とRing3遷移

## 概要

ELFローダーでロードしたプログラムをRing 3 (ユーザー空間) で実行する。
iretqによるRing 0→3遷移、syscall/sysretによるRing 3→0→3往復を実現。

## GDT再配置（必須）

sysret命令はSTAR MSRの[63:48]をベースに以下を計算する:
- User DS = base + 8
- User CS (64bit) = base + 16

現在のGDT配置（USER_CS=0x18, USER_DS=0x20）ではsysretが正しく動作しない。

### 変更前
```
0x00: NULL
0x08: Kernel CS
0x10: Kernel DS
0x18: User CS    ← sysretと不整合
0x20: User DS
0x28: TSS
```

### 変更後（Linux互換）
```
0x00: NULL
0x08: Kernel CS
0x10: Kernel DS
0x18: User DS    ← STAR base + 8
0x20: User CS    ← STAR base + 16
0x28: TSS
```

STAR sysret base = 0x10 → User DS = 0x18|3, User CS(64) = 0x20|3

## Ring 3遷移フロー

### 初回遷移: iretq
```
push USER_DS | 3     ; SS
push user_rsp        ; RSP
push 0x200           ; RFLAGS (IF=1)
push USER_CS | 3     ; CS
push entry_point     ; RIP
iretq
```

### syscall/sysret
- syscall: Ring3 → Ring0, RCXにRIP, R11にRFLAGS保存
- sysret:  Ring0 → Ring3, RCXをRIPに復帰

## Process 拡張

- user_stack: ユーザースタック先頭アドレス
- is_user: ユーザープロセスフラグ
