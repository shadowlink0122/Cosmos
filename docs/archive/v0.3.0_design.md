# v0.3.0 設計書: ネットワークスタックとソケット

## 概要

ループバックデバイス上にTCP/IPスタックを構築し、
BSD互換のsocket syscallを実装する。

## アーキテクチャ

```
 Socket API (socket/bind/listen/accept/connect/send/recv)
    ↓
 TCP / UDP / ICMP
    ↓
 IPv4 (ルーティング・チェックサム)
    ↓
 ARP (アドレス解決)
    ↓
 Ethernet フレーム
    ↓
 Loopback デバイス (127.0.0.1)
```

## ネットワークバッファ設計

```
struct NetBuf {
    ulong data;        // バッファ先頭アドレス
    ulong len;         // データ長
    ulong capacity;    // バッファ容量
    ulong protocol;    // プロトコル種別
}
```

固定メモリ領域 (0xA00000〜) にパケットバッファプールを配置。

## TCP ステートマシン

```
CLOSED → LISTEN → SYN_RCVD → ESTABLISHED → FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT → CLOSED
CLOSED → SYN_SENT → ESTABLISHED → CLOSE_WAIT → LAST_ACK → CLOSED
```

## Socket テーブル

固定16エントリ。FDテーブルと同様の固定メモリ方式。
ソケットFDは通常FD (fd >= 3) として割り当て、fs_type = FS_SOCKET で識別。

## 制約事項

- 物理NIC (e1000/virtio-net) は未実装 → ループバックのみ
- IPv6 未対応
- TCP ウィンドウ制御は最小限 (固定ウィンドウ)
- 再送タイマーは PIT tick ベース
