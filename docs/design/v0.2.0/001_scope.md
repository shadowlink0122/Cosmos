> Phase 2前半: ハードウェア例外のキャッチと基本的な割り込み処理基盤の構築

v0.1.0で確立したカーネルブートストラップの上に、割り込みと例外の処理基盤を構築する。

## 実装タスク

### 2-1. IDT（割り込みディスクリプタテーブル）

| タスク | 詳細 | 状態 |
|-------|------|------|
| IDTエントリ構造体 | 16バイトのx86_64ゲートディスクリプタ定義 | ✅ |
| IDTテーブル定義 | 256エントリ分の配列確保 | ✅ |
| IDTR構造体 | ベースアドレス + リミット（`lidt`用） | ✅ |
| IDTロード | `lidt`命令でIDTを適用 | ✅ |

**新規ファイル:**
- `kernel/idt.cm` — IDT構造体定義、テーブル、ロード関数

> [!IMPORTANT]
> x86_64 Long ModeのIDTエントリは**16バイト**（32bitモードの8バイトとは異なる）。
> オフセットは3分割: bits 0-15, bits 16-31, bits 32-63。

**IDTエントリ構造（16バイト）:**
```
Offset 0-1:  ハンドラアドレス下位16ビット
Offset 2-3:  セグメントセレクタ（CS = 0x08）
Offset 4:    IST（0=使用しない）
Offset 5:    Type/Attributes（0x8E = Interrupt Gate, Ring 0, Present）
Offset 6-7:  ハンドラアドレス中位16ビット
Offset 8-11: ハンドラアドレス上位32ビット
Offset 12-15: Reserved（0）
```

**エラーコードがプッシュされる例外:**
| ベクタ | 名前 | エラーコード |
|-------|------|------------|
| 0 | ゼロ除算 (#DE) | なし |

| 8 | ダブルフォルト (#DF) | あり（常に0） |
| 13 | 一般保護例外 (#GP) | あり |
| 14 | ページフォルト (#PF) | あり |

## 技術的注意点

### __asm__ でのISRスタブ実装
```cm
// ISRの一般的なパターン
export void isr_stub_0() {
    __asm__(`
        push $0      ; ダミーエラーコード
        push $0      ; ベクタ番号
        jmp isr_common
    `);
}
```

### 割り込みフレーム
CPU例外発生時にスタックに自動プッシュされる情報:
```
[RSP+40] SS
[RSP+32] RSP（割り込み前）
[RSP+24] RFLAGS
[RSP+16] CS
[RSP+8]  RIP
[RSP]    エラーコード（ある場合）
```
